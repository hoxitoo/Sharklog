Всё что нужно профессионалу

От учёта ставок до глубокой аналитики — SharkLog растёт вместе с твоим опытом.

📋
Учёт ставок
Полная история с датой, спортом, букмекером, стратегией, турниром. 5 статусов: Победа, Поражение, Ожидание, Возврат, Выкуп.
📊
Дашборд
P&L-кривая, кривая ROI, стрип побед/поражений, тепловая карта активности за 12 недель, тилт-детекция.
🔬
Аналитика PRO
7 срезов: спорт, тип ставки, букмекер, стратегия, диапазон кэфов, день недели, час. Топ турниры.
💡
Инсайты PRO
Статистика по турнирам для всех. Карточки любимых команд (PRO) — только команды с ≥10 ставками.
💰
Банкролл PRO
Кривая капитала, история депозитов и выводов, юнит-стейкинг, калькулятор Келли с вероятностями.
🧠
Тилт-контроль
Автоматический алерт при N поражениях подряд. PRO: настраиваемый порог. Дневной лимит ставок.
🗓️
Дневник
Трекер настроения (1–5), 8 правил профессионала, личный дневник записей, тилт-статистика.
🎯
Билдер стратегий PRO
10 вопросов — персональная стратегия ставок. Значок стратегии на дашборде напоминает о правилах.
📥
Импорт / Экспорт
Импорт из CSV и Excel (.xlsx) — поддержка русских и английских заголовков. Экспорт в CSV и JSON.
🔒
Приватность
Все данные хранятся только на твоём устройстве. Никаких серверов, никаких аккаунтов — твои ставки видишь только ты.
🔄
Автообновления
Десктоп: автоматический апдейтер через GitHub Releases. Мобилка: OTA-обновления через Expo.
⌨️
Горячие клавиши
Ctrl+N — новая ставка, Ctrl+1..8 — навигация, Esc — закрыть. Десктоп оптимизирован для клавиатуры.
